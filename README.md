# Sites de demonstração

Sete prévias para apresentação aos clientes. Formulários, agenda e gestão usam simulações e dados fictícios; não processam reservas ou pagamentos reais.

Para publicar: Settings → Pages → Deploy from a branch → main → / (root).

Se a conta usa GitHub Free, GitHub Pages exige repositório público. Não incluir dados pessoais, credenciais ou propostas confidenciais.
